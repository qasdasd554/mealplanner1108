# 1.0.73+274 — oddzielne katalogi społeczności PL i UK

- Przepisy użytkowników są dostępne w katalogu wyłącznie w kraju konta autora:
  PL dla autorów PL, UK dla autorów GB. Akceptacja publicznego przepisu ani
  dostępność jego składników w innym kraju nie znoszą tej granicy.
- Filtr działa przed paginacją również w wyszukiwaniu, ulubionych,
  dopasowaniu składników, przepisach znajomych i generatorze planów.
- Zabezpieczone są szczegóły, komentarze, nowe listy zakupów, ulubione,
  zgłaszanie treści i zdjęć oraz powiadomienia o aktywności przepisu.
- Wspólne pozostają istniejące 137 przepisów systemowych z tłumaczeniami;
  przepisy użytkowników nie są kopiowane ani automatycznie tłumaczone.
- Właściciel zachowuje własne przepisy i ich edycję; administrator zachowuje
  jawny dostęp moderacyjny do obu rynków.
- Powiadomienie o aktualizacji zawiera informację o oddzieleniu społeczności.

Bez nowej fizycznej bazy, migracji i usuwania danych. Kraj konta pozostaje stały.
Poprzedni ZIP 1.0.72+273 nie zawierał tej poprawki i nie jest podmieniany.
